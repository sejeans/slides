## 학생들이 빈 공간을 찾는 데 쓰는 시간과 원인

---

# 문제 정의
> 학생들은 빈 자리를 찾느라 하루 평균 ==14분==을 쓰며, 원인은 실시간 정보의 부재임

- **현황** — 교내 설문(412명) 결과 빈 강의실·열람실 탐색에 하루 평균 14분 소요
  - 시험 기간에는 평균 23분으로 증가
  - 응답자의 61%가 "건물을 직접 돌아다니며 확인"한다고 답함
- **원인** — 공간 정보가 시간표 기준으로만 제공되어 실제 사용 현황과 다름
  - 시간표상 빈 강의실의 38%가 실제로는 자습·스터디로 사용 중
- **목표** — 15분 뒤 강의실 혼잡도를 예측해 이동 전에 확인할 수 있게 함
source: 교내 설문조사(2026.09, n=412)

# 데이터 구성
> 16개월간 86개 강의실의 5분 단위 접속 기기 수(약 ==2.1억 건==)를 사용함

| 구분 | 내용 | 규모 |
|---|---|---|
| 수집 기간 | 2025.03 – 2026.06 (방학 포함) | 16개월 |
| 대상 공간 | 공학관·제2공학관·도서관 강의실·열람실 | 86곳 |
| 원천 데이터 | AP별 접속 기기 수, 5분 단위 집계 | ==2.1억 건== |
| 외부 변수 | 시간표, 학사일정(시험·축제), 요일·공휴일 | 4종 |

→ 방학 기간을 포함해 학기 중과 비학기의 패턴 차이를 함께 학습할 수 있도록 구성함
source: 교내 정보화본부 접속 로그(2026.07 추출)

---

# 전처리 및 모델링
> 상주 기기를 제거한 뒤 시간표·학사일정 변수를 더해 LightGBM으로 예측함

1. **정제** — 교직원·상주 기기 제외
  - 하루 10시간 이상 같은 AP에 접속한 기기를 상주 기기로 판단
  - 전체 기기 수의 약 9% 제거
2. **변수 생성** — 시간대·요일·직전 1시간 추세, 시간표상 수업 여부, 시험 기간 여부
3. **학습** — 15분 뒤 점유율(접속 기기 수 ÷ 좌석 수)을 LightGBM으로 회귀 예측
  - 2026.05–06을 검증 기간으로 분리, 나머지로 학습
4. **서비스** — 5분마다 예측을 갱신해 웹 지도에 색으로 표시

# 시간대별 혼잡 패턴
> 공학관은 ==오후 2–4시==에 점유율이 90% 안팎으로 몰리고, 도서관은 하루 종일 완만함

# 모델별 예측 성능
> LightGBM이 정확도 92%로 가장 높았고, 학습 시간도 4분으로 가장 짧았음

| 모델 | MAE | 정확도 | 학습 시간 |
|---|---|---|---|
| 이동평균 | 8.4 | 71% | — |
| ARIMA | 6.1 | 79% | 12분 |
| LightGBM | 3.2 | 92% | 4분 |
highlight: 3

- **정확도 기준** — 실제·예측 혼잡 단계(여유·보통·혼잡)가 같은 비율
- **오차가 큰 구간** — 시험 기간 저녁(MAE 6.8), 평소와 패턴이 달라 학습 데이터가 부족

# 요약 및 향후 과제
> 접속 로그만으로 15분 뒤 혼잡도를 92% 정확도로 예측할 수 있음을 확인함

### 성과
- 탐색 시간 14분 → 3분 (베타 테스트 38명, 2주)
- 추가 센서 없이 기존 와이파이 인프라만 활용

### 한계와 다음 단계
- **시험 기간 오차** — 과거 시험 기간 데이터를 가중 학습

- **학교 앱 미연동** — 학생지원처와 연동 범위 협의 중
